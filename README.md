# 🎮 Nimlyx

A modern Steam analytics and game discovery platform built with Flask, Python, JavaScript, and Steam's public APIs.

Nimlyx helps PC gamers discover, explore, and analyze Steam games through intelligent search, curated discovery, community insights, deals, and detailed game pages.

> **Analyze. Explore. Discover.**

---

# ✨ Features

## 🏠 Homepage

- Featured hero carousel
- Trending games
- Top Sellers
- Biggest Deals
- Free-to-play games
- Dynamic Steam-powered sections
- Responsive glassmorphism interface
- Real-time Steam data integration

---

## 🔍 Advanced Game Search

- Live search suggestions
- Dedicated search experience
- App ID-based game routing
- Smart search results flow
- Exact match detection
- Multi-result discovery
- Mobile-optimized layouts
- Right-click / new-tab friendly navigation
- Cached search results for faster browsing

### Game Details

- High-resolution game artwork
- Screenshot gallery
- Game trailers when available
- Genre information
- Developer and publisher details
- Steam review information
- Metacritic score
- Platform support
- Release date
- Pricing and discounts

---

## 🧭 Discover Engine

A dedicated discovery experience designed to help players find games beyond traditional Steam browsing.

- Steam-powered game discovery
- Advanced filtering
- Budget filters
- Genre filtering
- Platform filtering
- Live results
- Infinite scrolling
- URL-synced preferences
- Premium game card experience
- Curated discovery sections

---

## 🧠 Nimlyx Analysis

Nimlyx provides custom insights designed to go beyond Steam's standard game information.

### Analysis includes:

- Nimlyx Score
- Reputation trajectory
- Community pulse
- Tag honesty analysis
- Review spotlight insights
- Data-driven game evaluation

---

## 🎮 Game Pages

Detailed game pages bringing Steam information together into one experience.

- Cinematic hero section
- Developer and publisher credits
- Quick statistics
- Pricing and discount information
- Review score breakdown
- Screenshots and trailers
- More From Developer carousel
- More From Publisher carousel
- Similar and related game discovery

---

# ⚙️ Backend

Nimlyx uses a modular Flask backend designed around Steam data retrieval, processing, caching, and reusable services.

- Flask REST API
- Steam Store API integration
- Steam search integration
- BeautifulSoup web scraping
- Optimized Steam caching
- Reusable scraping services
- Canonical JSON contracts
- Modular service architecture
- Concurrent data fetching
- Server-side performance optimizations
